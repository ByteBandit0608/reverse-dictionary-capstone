# reverse dictionary

given a definition, return the word. OPTED dictionary (Webster's 1913), english, Kaggle for the
compute. IIIT-H DFL capstone, NLP-02, mentor Ekansh Goyal, 8 weeks with no extension.

what the brief wants: retrieval and neural approaches, Recall@1/10/100 and median rank on 500
held out definition queries, a comparison against a neural model, error analysis on about 20
failures, and a Gradio demo at the end.

## layout

    data/        the OPTED csv, committed so it can be checked
    src/         rexdict.py is the loader and the metrics, the others are entry points
    splits/      the by-word split, the 500 query ids, a manifest with the counts
    results/     the tables, all generated by the scripts
    tests/       checks on the metric code
    notebooks/   the EDA notebook from week 2

notes.md has the decisions and the measured numbers. read it before the results, some of the
numbers mean the opposite of what they look like on their own.

## running

    pip install -r requirements.txt
    python src/run_all.py

that writes splits/ and results/. Kaggle version is at the bottom of notes.md. nothing here needs
a gpu. everything is seeded (2026) so a re-run gives the same tables.

    python tests/test_metrics.py     # checks the scoring code by hand, no data needed
